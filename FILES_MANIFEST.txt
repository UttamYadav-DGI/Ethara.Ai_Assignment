QUICK START
========================================

1. Backend Setup:
   cd backend
   npm install
   cp .env.example .env
   npm run dev

2. Frontend Setup (new terminal):
   cd frontend
   npm install
   cp .env.example .env
   npm run dev

3. Access Application:
   http://localhost:5173
